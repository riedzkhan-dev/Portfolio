# NexusFlow Complete

A fully working front-end project management and IT ticketing demo.

## How to run
1. Extract the ZIP.
2. Open the extracted folder.
3. Double-click `index.html`.

## Included files
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## Demo features
- Login with selectable role
- Dashboard
- Projects
- Kanban drag-and-drop
- Tickets with create/delete/search/filter
- Sprints
- Reports
- Team page
- Notifications
- CSV export
- Theme toggle
- LocalStorage persistence
- Reset demo data

## Important
This is a working front-end portfolio application. It uses browser LocalStorage instead of a real server database.
