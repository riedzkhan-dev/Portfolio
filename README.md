# Riedzkhan 3D Cinematic Portfolio — Updated

This package contains the complete portfolio website plus the NexusFlow Enterprise project.

## Deploy to Netlify
1. Extract the ZIP.
2. Upload the entire `Riedzkhan_Portfolio_Updated` folder to your existing Netlify site.
3. Keep the `nexusflow` folder inside the portfolio folder.

## Main pages
- `index.html` — portfolio homepage
- `nexusflow/index.html` — NexusFlow live demo

The portfolio Projects section now includes NexusFlow as the flagship project.
